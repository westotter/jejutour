# 제주 한 걸음

> 제주의 이야기를 따라, 오늘도 한 걸음.

**제주 한 걸음**은 제주 원도심의 역사 유적과 문화·예술 공간을 발견하고, 나만의 산책 계획을 만드는 웹 앱입니다. 장소의 소개와 주소를 살펴보고, 가고 싶은 곳을 방문 리스트에 담아보세요. 꼭 기억하고 싶은 계획은 문구 일부를 하이라이트하거나 별표로 강조할 수 있습니다.

HTML, CSS, JavaScript만으로 구현해 별도의 패키지 설치나 빌드 없이 실행할 수 있습니다.

## 주요 기능

- **장소 탐색**: 원도심의 유적과 예술 공간 5곳의 소개와 주소를 확인합니다.
- **분류와 검색**: 전체·역사 유적·문화 예술 필터를 선택하거나 장소명, 주소, 소개에 포함된 문구로 검색합니다.
- **위치 확인**: 개략 위치도의 마커를 누르면 해당 장소 카드가 강조됩니다. 카드의 ‘지도 보기’는 카카오맵 검색 결과를 새 탭으로 엽니다.
- **나의 산책 리스트**: 장소를 방문 계획에 담거나 직접 할 일을 작성하고, 완료하거나 삭제합니다. 이미 담은 장소는 중복 추가되지 않습니다.
- **부분 하이라이트**: 할 일 문구를 드래그해 중요한 부분만 강조하거나 선택한 부분의 강조를 지웁니다.
- **전체 중요 표시**: 별 버튼으로 할 일 전체의 강조를 켜고 끕니다.
- **완료율 표시**: 전체 할 일 중 완료한 항목의 비율을 확인합니다.
- **자동 저장**: 방문 계획, 완료 상태, 중요 표시, 하이라이트를 브라우저에 저장합니다. 같은 저장 영역을 사용하는 다른 탭에도 변경 사항을 반영합니다.
- **반응형 화면**: 데스크톱과 모바일 화면 크기에 맞춰 배치가 조정됩니다.

## 소개하는 장소

| 장소 | 분류 | 주소 |
| --- | --- | --- |
| 제주목 관아 | 역사 유적 | 제주시 관덕로 25 |
| 관덕정 | 역사 유적 | 제주시 관덕로 19 |
| 예술공간 이아 | 문화 예술 | 제주시 중앙로14길 21 |
| 산지천갤러리 | 문화 예술 | 제주시 중앙로3길 36 |
| 오현단 | 역사 유적 | 제주시 오현길 61 |

위치도는 장소의 상대적인 배치를 보여주는 **개략도**입니다. 축척 지도나 길 안내 기능은 제공하지 않으므로 정확한 위치는 각 카드의 ‘지도 보기’로 확인하세요. 운영 시간과 전시 일정은 실시간으로 제공하지 않습니다.

## 실행 방법

1. 프로젝트 파일을 내려받습니다.
2. `index.html`, `style.css`, `app.js`를 같은 폴더에 둡니다.
3. `index.html`을 최신 웹 브라우저에서 엽니다.

별도의 서버나 회원가입은 필요 없습니다. 프리텐다드 폰트와 대표 사진을 불러오거나 외부 지도를 이용하려면 인터넷 연결이 필요합니다. 폰트를 불러오지 못하면 시스템 폰트를 사용합니다.

## 사용 방법

1. **장소 둘러보기**에서 분류를 선택하거나 검색어를 입력합니다.
2. 위치도의 마커를 눌러 장소 카드를 확인합니다.
3. **지도 보기 ↗**로 위치를 확인하고, **+ 산책에 담기**로 방문 계획을 추가합니다.
4. **나의 산책 리스트** 입력란에 원하는 할 일을 적고 `+` 버튼 또는 Enter 키를 눌러 추가합니다.
5. 체크박스로 완료 상태를 변경하고, `×` 버튼으로 항목을 삭제합니다.
6. 중요한 문구를 드래그한 뒤 **하이라이트**를 누릅니다. 선택한 부분의 강조는 **강조 지우기**로 제거합니다.
7. `☆` / `★` 버튼으로 항목 전체의 중요 표시를 설정하거나 해제합니다.

처음 실행하면 기능을 살펴볼 수 있도록 예시 산책 계획 두 개가 표시됩니다.

## 디자인

- **폰트**: 프리텐다드(Pretendard)
- **포인트 컬러**: 주홍색 `#ed593b`
- **배경**: 따뜻한 아이보리와 CSS로 만든 작은 삼각형 애니메이션
- **표현 방식**: 그라데이션과 SVG 이미지 없이 구성
- **접근성**: 키보드 포커스 표시, 입력 요소와 버튼의 접근성 이름, 상태 안내
- **동작 줄이기**: `prefers-reduced-motion` 설정에 따라 애니메이션과 전환 효과를 줄임

## 기술 구성

| 기술 | 역할 |
| --- | --- |
| HTML5 | 페이지 구조, 장소 목록, 방문 계획 입력 폼 |
| CSS3 | 색상, 반응형 레이아웃, 삼각형 배경 애니메이션 |
| JavaScript | 장소 검색·분류, 리스트 관리, 완료율 계산 |
| Selection / Range API | 선택한 문구의 하이라이트 처리 |
| localStorage | 방문 계획과 강조 상태 저장 |
| 카카오맵 검색 링크 | 외부 지도에서 장소 위치 확인 |

## 파일 구조

```text
.
├── index.html   # 화면 구조와 폰트 연결
├── style.css    # 디자인, 반응형 스타일, 배경 애니메이션
├── app.js       # 장소 데이터, 검색, 방문 리스트, 하이라이트
└── README.md    # 서비스 소개와 사용 안내
```

장소 데이터를 수정하려면 `app.js`의 `places` 배열에서 이름, 분류, 주소, 소개, 출처를 변경하세요. `x`와 `y`는 개략 위치도 내 마커의 백분율 위치이며 실제 위도·경도가 아닙니다.

## 데이터 저장 안내

방문 리스트는 서버로 전송하지 않고 사용 중인 브라우저의 `localStorage`에 저장합니다. 저장 키는 `jeju-one-step-v1`입니다.

- 같은 브라우저와 실행 위치에서 다시 열면 저장된 내용을 불러옵니다.
- 브라우저나 기기가 바뀌면 데이터가 자동으로 공유되지 않습니다.
- 브라우저의 사이트 데이터를 삭제하면 저장한 방문 계획도 사라집니다.
- 브라우저 설정이나 저장 공간 제한으로 저장에 실패하면 화면에 안내합니다.

현재 로그인, 클라우드 동기화, 실시간 전시 정보, 경로 계산 기능은 제공하지 않습니다.
